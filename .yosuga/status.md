## Decisions

- 2026-07-27 **レコルを廃止する** — 残っていた仕事3つのうち、文書の分類は
  `documents` を作る経路が手打ち1箇所(`RecordsViewModel.addDocument`)だけで実機0件、
  `items[]` はそれに連動 + ヨスガが直接出せるため二重、指示書は **v4.2 まではヨスガの仕事**で
  移した理由は「配信中の指示を Actions で読んで重複を防ぐため」だけだった。
  **設備(ロリポップ同期・Actions・openapi.yaml・サーバーPHP・documents/classifications)は
  削除せず維持する。** Room の変更なし。
- 2026-07-27 **ヨスガへの指示文は Hub が毎回同梱する** — メモリは中身を確かめられず、
  いつ薄れたかも分からず、新しい会話では効き方が違う。v5 の「Hub は運ぶ」に照らせば
  指示文もまた運ぶべき情報。例外は**観察日誌の文体規則**だけ(メモリ側が正)。
- 2026-07-27 **セッション記録は承認を挟まず Obsidian へ直接書く** —
  Hub のデータを変える提案ではなく記録そのもので、正本は Obsidian にある。
  中身を読まずに承認するだけの画面は、承認の意味を薄くする。
- 2026-07-27 **セッション記録の Frontmatter は Hub が組む** — AI に YAML を書かせると
  引用符やコロンで壊れ、**Obsidian は壊れた Frontmatter を無いものとして扱う**ため
  検索から静かに消える。構造化された値だけを出させる。
- 2026-07-27 **切れた指示文は渡さない** — `?q=` は上限超過を黙って切る。
  日本語は URL エンコードで1文字9バイトになり、実際の指示文(450〜1250字)は載らない。
  `ChatGptLink` は入り切らないと分かった時点で `q` を諦め、クリップボードに任せる。
- 2026-07-26 **朝の近況は Hub からヨスガへ直接渡す(Morning Brief 廃止)** —
  現況JSONが Brief の材料をすべて持っていた。7節のうち5節は選別で Hub が渡せる。
  締切や停滞の指摘はヨスガができ、`シロの状態` はヨスガが書いた観察日誌を
  レコル経由で本人へ返していた。v4.3 の「知識を活かすのはレコルではない」に戻す。
- 2026-07-26 **仕分けは各ゲームの Claude Code に任せる** —
  v5 の「意味付けは生成元が出力時点で行う」が実機で動いていた(Frontmatter → NoteRouter)。
  レコルに残るのは記録タブに手打ちした `documents` の分類だけで、実機では0件。
  ロリポップ同期・Actions は維持するが必須ではない。
- 2026-07-24 **設計を v5「Obsidian ブリッジ」へ転換**
- 2026-07-25 **クリップボードの自動読み取りは採らない** — Android 12 以降は
  読むたびにトーストが出て抑制できないため。共有シートで受ける。
- 2026-07-25 **期間で絞るとき、判断できないものは捨てない** — 静かに減るより多くて正直を選ぶ。
- 2026-07-25 **サンプルデータを機能ごと廃止する**
- 2026-07-25 **プロジェクト ID は自動採番しない** — 正本なので人が決める。作成後は変更不可。
- 2026-07-25 **プロジェクトの呼称は英字名にする** — 表示名は Obsidian のフォルダ名にもなる。
- 2026-07-25 **Vault は更新反映する。ただし削除は報告のみ** — GitHubのノートは
  Claude Code だけが書くので上書きしない前提が外れた。削除は Vault が人の領分なので機械が消さない。
- 2026-07-25 **ヨスガへ渡す口は1つ**(現況は既定・過去ログは任意)
- 2026-07-25 **AIの出力揺れはアプリ側で吸収する** — 封筒の無い回答JSONも受け取る。
  ただしプロンプトは正しい形を教え続ける。
- 2026-07-26 **実機=運用機 / エミュレータ=テスト機 に分ける** —
  `connectedDebugAndroidTest` は実機に運用データを入れる前に一度だけ流し、以後回さない。
- 2026-07-26 **`server/config.php` を Git 管理外にする** — 本番トークンを平文で
  追跡しており public リポジトリで公開されていた。ひな形 `config.example.php` を追跡する。
  公開されたものは取り消せないため、修復はトークンの作り直しで行った。
- 2026-07-26 **UI に古い設計の残骸を残さない** — 設定画面の「Googleアカウント: 未接続
  (Phase 4 で実装予定)」は CalendarContract 方式へ差し替えた時点で嘘になっていた。
  カレンダーが0件のとき、この表示が原因に見えて誤診を招いた。
- 2026-07-26 **入り口は共有シートを主・クリップボードを従とする** — 実機で両方通った。
  同じ回答JSONが2経路で同一サイズで届いた。懸念していた「共有がリンクだけ送る」は起きなかった。
- 2026-07-26 **Yosuga Hub 自身を Hub のプロジェクトとして登録する** —
  保留にしていた論点。上書き反映の検証で両側を制御できる対象が必要だったため登録した。
  `projectId` は `yosuga-hub`、表示名は `YosugaHub`(Vault の `Games/YosugaHub/` になる)。
